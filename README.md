Изменения подготовлены в отдельной ветке. На действующий сайт не опубликованы.

## Происхождение

В исходном Git-коммите `7f8bf0c` находились только шесть изображений (пять уникальных объектов). Действующая страница была вручную загружена в Netlify Drop, проект `salman05`. Редактируемый HTML восстановлен из её встроенного шаблона и ресурсов; исходный небезопасный JavaScript и секреты не импортированы. `recovery-provenance.json` описывает происхождение.

Резервная ветка: `codex/backup-before-security-20260916`. Работа: `codex/security-audit-20260916`. Старые PNG и их производные сохранены в локальной игнорируемой папке `work/retired-pinterest-assets/`. После сообщения владельца об источнике Pinterest они исключены из текущей версии исходников и сборки. История и резервная ветка не переписывались. Публикация использует только `public/` через сборку в `dist/`.

## Локальная проверка

Требуется Node.js 22+; фактически проверено Node.js 24.19.0, pnpm 11.19.0.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm lint
pnpm test
pnpm preview
```

Preview по умолчанию: http://127.0.0.1:4173. В текущей проверке запущен порт 4175. Порт задаётся переменной PORT. Для первичной проверки новой CSP можно установить CSP_REPORT_ONLY=1 перед запуском preview, затем обязательно проверить обычный режим. Сервер доступен только на этом компьютере.

Сайт статический, программных зависимостей и backend нет. `lint` проверяет синтаксис JavaScript; TypeScript не используется. Тесты проверяют сборку, ограничения обработки данных, CSP, структуру и ссылки. Сервер preview не является production-сервером и не предназначен для публикации в интернет.

## Архитектура

- Поля заявок удалены. Telegram, WhatsApp и телефон открываются обычными ссылками без параметров сообщения.
- Никаких ключей для работы этой версии не требуется. Имена в `.env.example` зарезервированы только для будущего согласованного серверного решения. Не заполнять их для текущего сайта.
- Страницы `/privacy/`, `/consent/`, `/terms/` — явно отмеченные юридические черновики. До утверждения не публиковать.
- HTTP-заголовки генерируются в `dist/_headers`, адреса без завершающего слеша — в `dist/_redirects`. CSP разрешает только локальные файлы и точный хеш Schema.org, запрещает сеть из скриптов, формы, встраивание, inline-стили и обработчики.
- При восстановлении backend потребуются отдельное проектирование, подтверждение российской базы, правовые основания, серверная валидация, защита от злоупотреблений и безопасное хранение согласий. Просто включить старую форму нельзя.

## Перед публикацией

Читайте AUDIT_REPORT.md, MANUAL_ACTIONS.md, LEGAL_INPUTS_REQUIRED.md, RKN_CHECKLIST.md, ASSET_RIGHTS_REVIEW.md и DATA_HANDLING_DRAFT.md. `asset-provenance.json` фиксирует происхождение новой графики и контрольные суммы исключённых изображений.

`pnpm release:check` намеренно блокирует production, пока подтверждения в `release-review.json` не получены. Переключать флаги только после фактической проверки; автоматический Git-build Netlify вызывает эту проверку. Ручная загрузка через Drop может обойти её, поэтому загружать сборку без отдельной команды владельца запрещено. Нельзя загружать корень репозитория, локальные резервные копии, `.env` и файлы аудита вместо `dist/`.

Не требуется добавлять nginx или выдуманный API на Netlify: серверные процессы текущей платформы управляются провайдером. Настройки аккаунтов, DNS и обработчиков проверяются отдельно.
