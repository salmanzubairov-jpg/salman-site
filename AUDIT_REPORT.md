## 3. Выбранная архитектура

Вариант Б: обычные ссылки Telegram, WhatsApp и телефон без полей, подготовленных персональных данных, clipboard и автоматической отправки. Российские backend/база не подтверждены; новый сервер и платные услуги не подключались. Серверные валидация, rate limiting, honeypot и журнал согласий здесь не создавались, потому что серверного приёма заявок нет. Новый API нельзя вводить без отдельного проектирования.

Секреты для текущего сайта не нужны. `.env.example` содержит только пустые TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID с пометкой о будущем серверном использовании; они никуда не подставляются. Поля, уведомления и Telegram API не остаются скрытым запасным сценарием.

Открытие мессенджера и дальнейшая переписка всё равно требуют правовой оценки. Netlify получает технические HTTP-запросы; отсутствие формы не подтверждает отсутствие персональных данных или российскую локализацию. Не доказаны география журналов/переписки, сроки, состав обработчиков и основания.

## 4. Технические изменения

- Сохранены расположение секций, основные изображения, цвета и шрифты. Восстановлены карточки услуг, FAQ и мобильное меню через details/summary с клавиатурой; Escape закрывает меню.
- Выделены локальные изображения и шрифты; PNG для web-версии переведены в WebP. Портрет сохранён исходным JPEG. Добавлены размеры, lazy loading ниже первого экрана, reduced-motion и кнопка паузы анимации. Лицензии Manrope/Unbounded OFL включены.
- HTML/CSS/JS без React, CDN и runtime eval. CSS вынесен из inline-атрибутов. Schema.org остаётся статическим JSON-LD с вычисленным CSP-хешем.
- CSP: default-src none, script/style/img/font только self (и точный JSON-LD hash), connect-src none, form-action none, frame-ancestors none, object-src none, base-uri none, worker-src none; нет unsafe-inline, unsafe-eval, blob и широких wildcard.
- X-Frame-Options DENY, nosniff, no-referrer, ограничительная Permissions-Policy, CORP same-origin. HSTS max-age=31536000 сохранён без изменения охвата поддоменов. Разрешающий CORS не добавлен: API нет.
- Для ручного Netlify deploy заголовки и redirect-файлы входят в dist. netlify.toml публикует только dist; проверки production-утверждения не пройдены намеренно. Прямой Drop обходит build-gate, поэтому требует отдельного разрешения.
- Добавлены manifest, sitemap, robots, 404 и security.txt. Нет случайного noindex и source maps. Отсутствующий URL действительно даёт 404. security.txt содержит срок 16.03.2027 и уже опубликованный рабочий контакт, а не личный выдуманный email.
