## 3. Выбранная архитектура

Вариант Б: обычные ссылки Telegram, WhatsApp, телефон и рабочая почта без полей, подготовленных персональных данных, clipboard и автоматической отправки. Российские backend/база не подтверждены; новый сервер и платные услуги не подключались. Серверные валидация, rate limiting, honeypot и журнал согласий здесь не создавались, потому что серверного приёма заявок нет. Новый API нельзя вводить без отдельного проектирования.

Секреты для текущего сайта не нужны. `.env.example` содержит только пустые TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID с пометкой о будущем серверном использовании; они никуда не подставляются. Поля, уведомления и Telegram API не остаются скрытым запасным сценарием.

Открытие мессенджера и дальнейшая переписка всё равно требуют правовой оценки. Netlify получает технические HTTP-запросы; отсутствие формы не подтверждает отсутствие персональных данных или российскую локализацию. Не доказаны география журналов/переписки, сроки, состав обработчиков и основания.

## 4. Технические изменения

- Сохранены расположение секций, портрет, цвета и шрифты; декоративные изображения заменены после уточнения источника Pinterest. Восстановлены карточки услуг, FAQ и мобильное меню через details/summary с клавиатурой; Escape закрывает меню.
- Выделены локальные изображения и шрифты. После уточнения происхождения прежние декоративные изображения исключены и заменены новыми SVG. Портрет сохранён исходным JPEG. Добавлены размеры, lazy loading ниже первого экрана, reduced-motion и кнопка паузы анимации. Лицензии Manrope/Unbounded OFL включены.
- HTML/CSS/JS без React, CDN и runtime eval. CSS вынесен из inline-атрибутов. Schema.org остаётся статическим JSON-LD с вычисленным CSP-хешем.
- CSP: default-src none, script/style/img/font только self (и точный JSON-LD hash), connect-src none, form-action none, frame-ancestors none, object-src none, base-uri none, worker-src none; нет unsafe-inline, unsafe-eval, blob и широких wildcard.
- X-Frame-Options DENY, nosniff, no-referrer, ограничительная Permissions-Policy, CORP same-origin. HSTS max-age=31536000 сохранён без изменения охвата поддоменов. Разрешающий CORS не добавлен: API нет.
- Для ручного Netlify deploy заголовки и redirect-файлы входят в dist. netlify.toml публикует только dist; проверки production-утверждения не пройдены намеренно. Прямой Drop обходит build-gate, поэтому требует отдельного разрешения.
- Добавлены manifest, sitemap, robots, 404 и security.txt. Нет случайного noindex и source maps. Отсутствующий URL действительно даёт 404. security.txt содержит срок 16.03.2027, Telegram и впоследствии подтверждённую владельцем рабочую почту.

## Решение о сохранении текущего хостинга

16.09.2026 владелец исключил восстановление платного Host-0, покупку нового хостинга и платной почты. Сохраняются Netlify для публикации и GitHub для исходников. Старый Host-0 был отключён намеренно. При чтении Рег.ру подтверждён активный домен до 05.07.2027, прочитаны три записи DNS, в том числе отдельная запись dagprice. Оплаты и изменения DNS не выполнялись, предварительный запрос поддержки отменён до отправки. Сборка уже подготовлена для Netlify; миграция на Рег.ру не требуется для применения технических исправлений. Проверка юридических условий текущей обработки остаётся открытой и не подменяется требованием купить хостинг.
