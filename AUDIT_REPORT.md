## Что именно проверено

Исходный Git-коммит 7f8bf0c содержал шесть PNG, но не исходный сайт. Действующая версия была загружена через Netlify Drop в проект salman05, deploy 6a6fc8f30862f57e7c88f83a. Из опубликованного шаблона восстановлена редактируемая статическая версия; небезопасный JavaScript не импортирован. Резервная ветка codex/backup-before-security-20260916 и локальный Git bundle сохраняют исходное состояние. История не переписывалась, оригинальные изображения и исходный HTML сохранены локально вне публикации.

Изменения находятся в codex/security-audit-20260916. GitHub хранит исходники; рабочий сайт размещён на Netlify. Рег.ру используется для домена/DNS. Владелец исключил продление Host-0 и любые новые платные услуги.

## Архитектура контактов

Выбран вариант Б из исходного поручения: Telegram, WhatsApp, телефон и email открываются обычными ссылками. Поля заявки, заранее заполненные персональные данные в URL, автоматическая отправка и Bot API отсутствуют. Российские backend и база не подтверждены. Новый сервер не создавался.

Новые ключи для работы сайта не нужны. В .env.example оставлены только пустые имена переменных для будущего отдельно согласованного серверного решения. Серверные проверки формы, rate limiting, honeypot и журнал согласий неприменимы к этой версии: серверного приёма заявок нет.

CSP запрещает сетевые запросы из JavaScript, формы, встраивание, плагины и рабочие потоки. Разрешены только собственные ресурсы и точный хеш статического JSON-LD. Нет unsafe-inline, unsafe-eval, wildcard или разрешающего CORS. Заголовки и redirects входят в dist для Netlify Drop. Код сайта не устанавливает cookies, localStorage, sessionStorage и аналитику. Обычные HTTP-запросы к хостингу и дальнейшая переписка во внешних сервисах всё равно требуют правовой оценки.

## Юридические сведения и границы готовности

ФИО, совершеннолетие, регион Кизляр, рабочая почта и контакты подтверждены владельцем. НПД подтверждён официальным сервисом ФНС на 16.09.2026. ИНН и подробное подтверждение сохранены только в игнорируемом локальном каталоге. Сведения о налоговых платежах не относятся к готовности сайта и здесь не исследуются.

Портрет владелец снял сам. Платных IT-клиентов, по его сведениям, ещё не было; наличие реальных заявок он достоверно подтвердить не может. Уведомления РКН, насколько ему известно, не подавались; официальный реестр не проверен. Отзыв токена закрывает отзыв, но не доказывает отсутствие последствий раскрытия.

Остаются: фактическая география и хранение технических журналов/переписки, правовые основания, адрес для официальных документов и проверка необходимости уведомлений. Нельзя заполнить эти факты вымышленными значениями или заменить их обещанием «данные нигде не хранятся». Готовый запрос к Netlify и конкретные действия по защите аккаунтов переданы владельцу отдельными локальными файлами.

Условия работы предусматривают письменное согласование объёма, цены, сроков, правок, приёмки, прав, сторонних расходов, поддержки и возврата. Демонстрационные иллюстрации не представлены как реальные клиентские заказы. Ни текст сайта, ни этот аудит не заменяют договор или правовую оценку обработки данных.

## Публикация и оставшиеся действия

1. Просмотреть http://127.0.0.1:4175/ на этом компьютере.
2. Получить недостающие сведения провайдера и закрыть правовую модель по LEGAL_INPUTS_REQUIRED.md и RKN_CHECKLIST.md. Документы не объявлять вступившими в силу до утверждения.
3. Выполнить личные действия по защите аккаунтов и проверке последствий раскрытия токена. Повторный /revoke без новой причины не требуется.
4. После закрытия обязательных вопросов получить отдельную команду владельца на публикацию, предусмотренную исходным поручением. Не загружать корень репозитория вместо dist. Не менять main и DNS автоматически.
5. После выпуска проверить фактический сайт; отдельно согласовать работу со старыми deploy/permalink. Они могут сохранять отозванный токен и прежние изображения. Историю Git и старые публикации автоматически не удалять.
