Для конфиденциального первичного сообщения используйте уже опубликованный рабочий контакт: Telegram @salmzyb. Публичная электронная почта пока не подтверждена.

Укажите адрес страницы, краткое описание, время обнаружения и безопасные шаги воспроизведения. Не передавайте действующие ключи, персональные данные посетителей или выгрузки переписки. Сначала согласуйте безопасный способ передачи чувствительных доказательств.

Не используйте обнаруженные токены, не изменяйте чужие данные и не создавайте нагрузку. Эта страница не даёт разрешения на вторжение, не устанавливает программу вознаграждений и не обещает срок ответа. Для машинного обнаружения контакта доступен security.txt.
