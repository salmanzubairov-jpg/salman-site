2. Что происходит при посещении

На сайте нет полей имени, телефона и описания задачи, серверного приёма заявок, прямого вызова Telegram Bot API и автоматической отправки сообщений. Шрифты, изображения, стили и скрипт загружаются с самого сайта.

Для доставки страницы браузер обращается к хостингу Netlify. При этом провайдер получает технические сведения соединения, в том числе IP-адрес, время запроса, адрес ресурса и сведения о браузере. Соглашение Netlify об обработке данных включает сведения посетителей размещённых сайтов, в том числе IP-адреса. Точный состав сохраняемых журналов, сроки и доступные настройки для этого проекта ещё уточняются у провайдера. Отсутствие формы не означает отсутствие обработки технических данных.
